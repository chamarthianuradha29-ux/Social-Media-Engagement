This project features an interactive Power BI dashboard designed to track, analyze, and visualize user engagement across key social media platforms, including Facebook, Instagram, and Twitter. By transforming raw performance metrics into actionable business insights, the dashboard helps measure content effectiveness, track audience reach, and optimize digital marketing strategies.

📊 Key Features & Visualizations
KPI Performance Overview: Single-card visuals highlighting core metrics such as total impressions, audience reach, total interactions, and average engagement rates.

Cross-Platform Analytics: Comparative charts evaluating post performance and user participation across different social media channels.

Trend & Time-Series Analysis: Line graphs tracking engagement fluctuations over time to identify peak audience activity windows.

Interactive Filtering: Dynamic slicers allowing users to filter metrics seamlessly by date ranges, platform type, and content categories.

🛠️ Tools & Technical Skills
Business Intelligence: Power BI Desktop

Data Processing: Data cleaning, transformation, and structural preparation

Data Modeling: DAX (Data Analysis Expressions) for calculated measures, rates, and KPI summaries
